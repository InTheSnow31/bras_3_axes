Ce projet contient deux exemples
- le fichier ```main_cinematique_inverse.m``` calcule les angles nécessaires pour placer le bras sur un point en évitant l'obstacle.
- le fichier ```main_trajectoire_continue.m``` affiche la trajectoire du bras se déplaçant d'un point A à un point B en évitant l'obstacle, avec l'effecteur tenant un angle constant.
